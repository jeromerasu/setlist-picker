## Scaffolding the design + harness foundation

Adds the docs that scope what we're building and the harness that lets contributors fire and implement individual tickets without rehashing decisions.

### Design docs

- `docs/PRD.md` — problem, goals, personas, scope v1, scope v2, open questions.
- `docs/ARCHITECTURE.md` — stack, data model, API surface, real-time strategy, offline strategy, external integrations.
- `docs/ROADMAP.md` — 10-week phased plan.
- `docs/CODEBASE_GUIDE.md` — orientation map; populates as code lands.

### Architecture Decision Records

- `decisions/ADR-001-tech-stack.md` — Python/FastAPI backend, Next.js PWA frontend, SQLite for v1.
- `decisions/ADR-002-monorepo-structure.md` — single repo, Turborepo for TS, Python as a sibling.
- `decisions/ADR-003-auth-model.md` — anonymous group code, no signup.
- `decisions/ADR-004-offline-strategy.md` — service worker + IndexedDB write queue + last-write-wins reconciliation.
- `decisions/ADR-005-music-data-source.md` — Spotify primary, Last.fm + genre-overlap fallback for similar artists (Spotify deprecated related-artists in late 2024).

### Feature specs (each with ticket breakdowns)

- `features/calendar-spec.md` — day view + week view + filter + conflict highlighting. 7 tickets.
- `features/friends-list-spec.md` — top-bar avatars + member dots + right-now view + group rename. 7 tickets.
- `features/artist-drilldown-spec.md` — modal with genre + similar artists + top-track preview, backed by cache. 11 tickets.

### Process

- `code_review_template.md` — 10-category review skeleton; reviewers fill every section.
- `code_review_known_fixes.md` — NF-001 through NF-006 catalog of recurring traps (use-client ordering, FE/BE field parity, render-time map guard, SSR-unsafe top-level reads, no bare except, no parallel Alembic migrations).
- `tasks/TASK_TEMPLATE.md` — fire-and-implement ticket template.

### What's NOT in this PR

- `CODE_OF_CONDUCT.md`, `.github/` workflow + templates, `README.md` update — landing in a follow-up.
- Any actual code — that comes per-ticket per the feature specs.
